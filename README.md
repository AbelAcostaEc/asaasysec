# Portafolio Profesional - Abel Acosta

¡Bienvenido al repositorio de mi portafolio profesional! Este proyecto es una aplicación web estática, moderna y de alto rendimiento desarrollada con **Astro** y **Sass**, diseñada para presentar mi perfil profesional como **Tecnólogo en Análisis de Sistemas** y **Desarrollador Full Stack**.

El sitio destaca mis habilidades en desarrollo web y móvil (Laravel, Angular, Ionic), automatización de procesos (con N8N) y mis proyectos más representativos.

---

## 🚀 Tecnologías Principales

Este portafolio está construido sobre una arquitectura moderna orientada a la velocidad de carga (Core Web Vitals) y una experiencia visual premium:

- **Framework**: [Astro v6](https://astro.build/) (modo estático para velocidad de carga óptima).
- **Estilos**: [Sass (SCSS)](https://sass-lang.com/) estructurado bajo patrón modular.
- **Procesamiento de Imágenes**: [Sharp](https://sharp.pixelplumbing.com/) para compresión y formatos modernos (.webp).
- **Tipografía**: Geist Sans y Inter servidas localmente.

---

## 🎨 Sistema de Diseño (Branding)

El proyecto cuenta con un sistema de diseño oscuro y futurista de alta fidelidad:

- **Ink (`#0B0F19`)**: Fondo principal de la aplicación.
- **Cloud White (`#F8FAFC`)**: Texto principal y superficies legibles.
- **Core Cyan (`#00C2FF`)**: Acciones, botones principales, énfasis y enlaces.
- **Signal Cyan (`#3BE8FF`)**: Detalles luminosos, glows de borde, efectos de foco y hovers interactivos.

## 📁 Estructura del Proyecto

La estructura del código está organizada de la siguiente manera:

```text
/
├── public/                  # Archivos estáticos directos (fuentes, favicon, robots.txt, etc.)
├── src/
│   ├── assets/              # Recursos gráficos (imágenes del portafolio, logotipos vectoriales)
│   ├── components/          # Componentes de UI modulares (Navbar, Footer, Hero, Proyectos, etc.)
│   ├── data/                # Datos centralizados en JSON (información de perfil, proyectos en JS)
│   ├── layouts/             # Plantilla HTML base del portafolio (Layout.astro)
│   ├── pages/               # Páginas y rutas del sitio (Index y sección del Blog)
│   ├── scripts/             # Scripts JavaScript para interacciones del cliente
│   └── styles/              # Arquitectura Sass (variables, mixins, estilos base y de componentes)
├── package.json             # Dependencias del proyecto y scripts
└── astro.config.mjs         # Configuración del compilador Astro
```

## 🧞 Comandos de Desarrollo

Todos los comandos se ejecutan desde la raíz del proyecto en tu terminal:

| Comando | Acción |
| :--- | :--- |
| `npm install` | Instala todas las dependencias necesarias. |
| `npm run dev` | Inicia el servidor de desarrollo local en `http://localhost:4321/asaasysec`. |
| `npm run build` | Compila el portafolio y genera el sitio estático optimizado en la carpeta `./dist/`. |
| `npm run preview` | Previsualiza localmente el build de producción antes de subirlo. |
| `npm run astro ...` | Ejecuta comandos CLI de Astro directamente (ej. `astro check`). |
